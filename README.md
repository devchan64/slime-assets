# SLIME Assets

SLIME 게임에서 채택한 공개 에셋의 관리 저장소다.

## 초기 관리 범위

| 디렉터리 | 대상 |
|---|---|
| `assets/tiles/` | 지면·벽·지붕 등 타일 텍스처 |
| `assets/sprites/` | 캐릭터·몬스터·오브젝트·이펙트 스프라이트와 재생 메타데이터 |
| `assets/maps/` | 게임 실행용 맵 데이터와 에셋 참조 |

관리 ID·버전·경로·해시는 `asset-registry.yaml`에서 관리한다. 최초 상태는 빈 등록부이며 기존 저장소의 에셋은 아직 이관하지 않았다.

## 등록 원칙

- 사용자가 채택한 에셋만 등록한다. 실험 결과나 후보는 자동 등록하지 않는다.
- 기존 관리 ID를 유지하고, 변경된 에셋은 새 버전으로 등록한다.
- 파일과 공개 가능한 출처·해시·제작 도구·라이선스 정보를 함께 관리한다.
- 내부 프롬프트·개인 경로·인증정보·비공개 기획 및 설계 자료는 포함하지 않는다.
- 모델 가중치, 생성기, 로그, 모션·리그 제작 자산, UI 이미지와 오디오는 초기 범위에서 제외한다.
- 공개 저장소라는 사실은 개별 에셋의 사용 허가를 뜻하지 않는다. 재사용 조건은 에셋별 라이선스 정보를 따른다.

## 소비 저장소와의 연결

프론트엔드는 검증된 버전 또는 커밋으로 에셋을 명시적으로 가져온다. `../slime-assets` 같은 로컬 상대 경로를 게임 런타임 의존성으로 사용하지 않는다. 기존 게임은 이관과 소비 코드 변경이 완료될 때까지 현재 에셋을 사용한다.

생성·검수·크롭은 `slime-workflow`, 렌더링·재생 코드는 `slime-frontend`, 비공개 설계 문서는 `slime-backend`에서 관리한다. 이 저장소에는 공개 가능한 게임 실행용 산출물만 전달한다.
