# 기본 캐릭터 에셋

애니메이션은 `animations/<동작>/<복장>/<시트 버전>/`에 둔다. 대기·휴식·걷기는 각각 `idle`, `rest`, `walk`이며 현재 경량 가죽 복장은 `light-leather`다. 시트 이미지와 재생·앵커 메타데이터, 출처 파일은 같은 버전 폴더에서 관리한다. 버전과 관리 ID는 등록부를 기준으로 하며 파일명에 남은 이전 명칭은 호환성과 출처를 위해 유지한다.

감정 컷인은 `emotion-cutins/`에서 관리한다. 전투 컷인 원본과 표시 매핑은 등록부에서 `retired`로 보존하며 신규 제작·활성 소비 대상에서 제외한다. 이미지·메타데이터의 등록 ID와 해시는 저장소 루트 `asset-registry.yaml`에서 확인한다.
